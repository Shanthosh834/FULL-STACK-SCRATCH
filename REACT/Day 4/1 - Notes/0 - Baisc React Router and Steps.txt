1.  What is React Router?

    * React Router = A library that lets you navigate between pages in your React app.

    * Think of it like different pages in a website:

        * localhost:5173/ → Home page

        * localhost:5173/about → About page

        * localhost:5173/contact → Contact page

        * Install React Router
        -> npm install react-router-dom


        * WITHOUT Router:
            → One page app
            → Can't navigate
            → URL never changes

        * WITH Router:
            → Multiple pages
            → Navigate between them
            → URL changes! (/home, /about)
            → Back button works!

2. Explanations:
    * Other project we created other components and called them all same URL had only right to navigate with pages URL /pages we use router
    * Without Router                With Router
      All components on one page	Each component on different URL
      <UserCard /> shows on Home	/usercard shows UserCard
      <About /> shows on Home	    /about shows About
    * Without Router (All on one page):
        -> in app.jsx <home /> <about />  same url localhost:5173/
    * With Router (Each on different URL):
        -> in app.jsx <home /> <about />  different localhost:5173/home, localhost:5173/about
