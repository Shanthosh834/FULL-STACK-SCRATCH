    DAY 4: REACT ROUTER

1.  What is React Router?

    * React Router = A library that lets you navigate between pages in your React app.

    * Think of it like different pages in a website:

        * localhost:5173/ → Home page

        * localhost:5173/about → About page

        * localhost:5173/contact → Contact page

    Step 1: Install React Router
        -> npm install react-router-dom


        * WITHOUT Router:
            → One page app
            → Can't navigate
            → URL never changes

        * WITH Router:
            → Multiple pages
            → Navigate between them
            → URL changes! (/home, /about)
            → Back button works!
