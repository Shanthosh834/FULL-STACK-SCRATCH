
    Day 2 - PROPS + useState

1. PROPS
    1. What are Props?

        * Props = Data passed from a parent component to a child component.

        * Think of props like function parameters but for React components!

    2.  Why Props?

        * Make components reusable

        * Pass dynamic data to components

        * Components can show different content with same structure

    3. WHAT IS PROPS?
    
        * Props = Data passed from Parent to Child

    4. LIKE:
        * Parent = App.jsx
        
        * Child = UserCard.jsx

        * App sends data → UserCard receives it!

    5. Without Props (Problem):
        // Every card shows SAME data! ❌
        function UserCard() {
            return <h2>Shanthosh</h2>;
        }

        <UserCard />  // Shanthosh

    6. Every card shows DIFFERENT data! ✅
        // PARENT sends:
        <UserCard name="Shanthosh" age={22} />
        <UserCard name="Kumar" age={25} />
        <UserCard name="Sandy" age={21} />

        // CHILD receives:
        function UserCard({ name, age }) {
            return (
                <div>
                    <h2>{name}</h2>
                    <p>{age}</p>
                </div>
            );
        }

2. Props Syntax:

    1. Parent Component (Passing Props)

        function App() {
        return (
            <div>
                {/* Passing props to child */}
                <UserCard name="Shanthosh" age={22} city="Chennai" />
                <UserCard name="John" age={25} city="Mumbai" />
                <UserCard name="Mary" age={30} city="Delhi" />
            </div>
        );
        }

    2. Child Component (Receiving Props)

        function UserCard({ name, age, city }) {  // ← Receiving props
        return (
            <div>
                <h2>Name: {name}</h2>   // ← Using props
                <p>Age: {age}</p>       // ← Using props
                <p>City: {city}</p>     // ← Using props
            </div>
        );
        }

3. Props Flow:

    Parent (App.jsx)
        │
        │  Passes props: name="Shanthosh" age={22}
        ▼
    Child (UserCard.jsx)
        │
        │  Receives: { name, age }
        ▼
    Renders: Name: Shanthosh, Age: 22


    * Props are used for components. The parent sends data (ARGUMENT) and the child receives it (PARAMETER).
